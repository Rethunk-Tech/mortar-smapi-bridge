# Security policy

The licence is in [`LICENSE`](LICENSE). The shipped artifact is a SMAPI mod that listens on loopback only and authenticates each command with a per-run token in a user-only state file.

## Reporting a vulnerability

Do not open an issue for a security report. Use GitHub's private vulnerability reporting on this repository, or contact the Rethunk-AI organisation maintainers privately, with a description, the affected paths or version, the SMAPI version in use, steps to reproduce, and the impact.

## Supported versions

Only the tip of `main` is supported.
